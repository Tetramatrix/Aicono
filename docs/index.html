Common questions.

Quick answers before you download.

Does Aicono cost anything?

Aicono is completely free to download and use. You can connect local AI models (Lemonade, Ollama, Llama.cpp) that run offline, or use cloud APIs with your own key for better accuracy.

Does Aicono leave my desktop untouched?

You define a custom Working Area in the main window. Icons outside that area are left completely untouched, and the visual editor lets you restore previous layouts at any time.

Can I run Aicono from a USB stick?

Yes. Aicono is a portable executable. Extract it anywhere and run it. No installation, no registry changes, no admin rights required.

What AI models are supported?

The built-in lightweight model runs fully offline. For better accuracy, connect Lemonade, Ollama, Llama.cpp, or cloud services like OpenAI and Mistral. The Model Manager lets you browse, favorite, and probe models.

What happens if Windows Auto-Arrange is on?

Disable Windows Auto-Arrange for best results. Right-click your Desktop > View > uncheck Auto-arrange icons. Aicono needs full control to arrange your layout.
